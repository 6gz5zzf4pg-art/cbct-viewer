# Interactive CBCT viewer

Static assets for the interactive cone beam CT viewer embedded on https://www.cjhenleydmd.com (Digital and 3D Imaging page).

- `index.html` – viewer (model-viewer + NiiVue, loaded from jsDelivr)
- `jaw.glb` – Draco-compressed bone/teeth surface mesh
- `jaw_volume.nii.gz` – 8-bit CBCT volume, 0.3 mm

De-identified scan of Dr. Henley's own jaws, shared with consent. No patient identifiers are present in any file.
